Spesifikasi Logika Bisnis & Algoritma Inti (Core Engine Rules)AI Agent wajib mengimplementasikan logika perhitungan dan struktur data berikut secara presisi:4.1 Struktur Data 5 Tipe Soal AKM (cbt_soal)Tipe 1 — Pilihan Ganda Tunggal (jenis = 1):opsi_a s/d opsi_e: HTML string (teks/gambar/LaTeX).jawaban: String huruf kapital tunggal ("A", "B", "C", "D", atau "E").Tipe 2 — Pilihan Ganda Kompleks (jenis = 2):opsi_a: JSON Object daftar opsi fleksibel, contoh: {"A": "<p>Opsi 1</p>", "B": "<p>Opsi 2</p>", "C": "<p>Opsi 3</p>", "D": "<p>Opsi 4</p>"}.jawaban: JSON Array huruf kunci, contoh: ["A", "C"].Tipe 3 — Menjodohkan / Matching (jenis = 3):Mendukung mode Daftar/Tabel maupun Tarik Garis (Line Connector) serta mendukung soal gambar menjodohkan dan soal gambar tanpa teks.jawaban: JSON Object dengan struktur:JSON{
  "type": "line",
  "mode": "1",
  "baris": ["Premis Kiri 1 (Teks/HTML <img>)", "Premis Kiri 2"],
  "kolom": ["Respon Kanan A (Teks/HTML <img>)", "Respon Kanan B", "Respon Kanan C"],
  "links": {
    "0": ["1"],
    "1": ["0", "2"]
  }
}
Aturan Validasi Status Terjawab: Pada antarmuka ujian siswa dan menu koreksi, soal menjodohkan hanya dianggap sudah dijawab apabila objek links milik siswa memiliki minimal 1 pasangan array yang tidak kosong (Object.values(links).some(arr => arr.length > 0)). Jangan menandai soal sebagai terjawab jika siswa baru mengklik titik awal tanpa menghubungkan garis.Tipe 4 — Isian Singkat (jenis = 4):jawaban: String jawaban singkat pasti.Aturan Koreksi Otomatis: Normalisasi string dengan strtolower(trim(strip_tags($jawaban_siswa))) === strtolower(trim(strip_tags($kunci))). Pastikan jawaban yang cocok secara teks langsung diberi skor penuh dan tidak dianggap salah akibat spasi berlebih atau perbedaan huruf kapital.Tipe 5 — Uraian / Essai (jenis = 5):
*Pada lembar ujian siswa, sediakan Rich Text Editor Header Jawaban Essai (Bold, Italic, Underline, List, Subscript/Superscript, Tabel sederhana) agar siswa dapat menulis jawaban terstruktur.4.2 Algoritma Pengacakan & Alias Opsi (QuestionRandomizerService)Saat siswa memulai ujian untuk pertama kali pada suatu id_jadwal:Ambil soal dari cbt_soal berdasarkan bank_id dan tampilkan = 1 sesuai kuota tampil_pg, tampil_kompleks, tampil_jodohkan, tampil_isian, tampil_esai.Jika cbt_jadwal.acak_soal == 1, acak urutan soal di dalam masing-masing kelompok jenis soal (atau lintas jenis) menggunakan algoritma Fisher-Yates Shuffle, lalu tetapkan urutan no_soal_alias dari 1 sampai N.Untuk soal PG (jenis = 1), jika cbt_jadwal.acak_opsi == 1:Ambil himpunan huruf sesuai cbt_bank_soal.opsi (misal 5 opsi: ['A','B','C','D','E']).Acak himpunan tersebut menjadi pemetaan alias: misal opsi_alias_a = 'C', opsi_alias_b = 'A', opsi_alias_c = 'E', opsi_alias_d = 'B', opsi_alias_e = 'D'.Saat disajikan ke layar siswa, teks opsi A yang dilihat siswa adalah isi dari kolom opsi_c milik cbt_soal.Saat siswa mengklik opsi A (jawaban_alias = 'A'), sistem otomatis mencari huruf asli yang berkorespondensi (opsi_alias_a $\rightarrow$ 'C') dan menyimpannya ke kolom jawaban_siswa = 'C'.Lakukan Bulk Insert seluruh baris cbt_soal_siswa untuk siswa tersebut dalam satu transaksi database.4.3 Rumus Perhitungan Skor Otomatis (AutoGraderService)Setiap tipe soal memiliki bobot persentase pada cbt_bank_soal: $B_{pg}, B_{pgk}, B_{jodoh}, B_{isian}, B_{esai}$. Total bobot maksimal adalah $B_{total} = B_{pg} + B_{pgk} + B_{jodoh} + B_{isian} + B_{esai}$ (umumnya $100$).Skor Pilihan Ganda ($S_{pg}$):$$S_{pg} = \left( \frac{\text{Jumlah PG Benar}}{\text{tampil\_pg}} \right) \times B_{pg}$$Skor Pilihan Ganda Kompleks ($S_{pgk}$):
Untuk setiap butir soal $i$, jika kunci memiliki $K_i$ jawaban benar dan siswa memilih $M_i$ jawaban benar serta $W_i$ jawaban salah:$$\text{Skor Butir } i = \max\left(0, \frac{M_i - W_i}{K_i}\right)$$$$S_{pgk} = \left( \frac{\sum \text{Skor Butir } i}{\text{tampil\_kompleks}} \right) \times B_{pgk}$$Skor Menjodohkan ($S_{jodoh}$):
Untuk setiap butir soal $i$, hitung total pasangan garis kunci ($L_{kunci}$) dan jumlah pasangan garis siswa yang tepat sama dengan kunci ($L_{benar}$). Jika jumlah total garis yang ditarik siswa ($L_{siswa}$) melebihi $L_{kunci}$, kurangi dengan kelebihan garis:$$\text{Skor Butir } i = \max\left(0, \frac{L_{benar} - \max(0, L_{siswa} - L_{kunci})}{L_{kunci}}\right)$$$$S_{jodoh} = \left( \frac{\sum \text{Skor Butir } i}{\text{tampil\_jodohkan}} \right) \times B_{jodoh}$$Skor Isian Singkat ($S_{isian}$):
Jika dikoreksi otomatis sesuai pencocokan string (atau dioverride guru di menu Koreksi):$$S_{isian} = \left( \frac{\text{Jumlah Isian Benar}}{\text{tampil\_isian}} \right) \times B_{isian}$$Skor Essai ($S_{esai}$):
Diambil dari penjumlahan nilai_koreksi yang diinput guru (atau pencocokan kata kunci awal) dibagi skor maksimal esai dikali $B_{esai}$.Total Nilai Ujian ($N_{total}$):$$N_{total} = S_{pg} + S_{pgk} + S_{jodoh} + S_{isian} + S_{esai}$$4.4 Rumus Katrol / Konversi Nilai UjianPada menu Rekap Nilai / Hasil Ujian, sediakan fitur konversi rentang nilai (Katrol Nilai) dari rentang nilai asli $[N_{min\_asli}, N_{max\_asli}]$ ke rentang target $[T_{min}, T_{max}]$:$$N_{konversi} = T_{min} + \left( \frac{N_{asli} - N_{min\_asli}}{N_{max\_asli} - N_{min\_asli}} \right) \times (T_{max} - T_{min})$$5. Protokol Pengerjaan Bertahap untuk AI Agent (Step-by-Step Build Plan)Saat mengeksekusi PRD ini, AI Agent harus mengerjakan proyek secara berurutan per tahap (Milestone) dan menunggu konfirmasi pengguna di setiap akhir tahap:Milestone 1 (Database & Core Framework): Buat seluruh file migrasi SQL (42 tabel beserta index), seeder awal, konfigurasi koneksi DB, helper fungsi (tanggal Indonesia, pencocokan string, pengacak Fisher-Yates), dan sistem autentikasi multi-role (Admin, Guru, Siswa).Milestone 2 (Modul Data Master): Bangun controller, model, dan view untuk Beranda, Tahun Pelajaran/Semester, Jurusan, Mapel, Ekskul, Siswa (CRUD + Import Excel + Foto per kelas), Kelas/Rombel (CRUD + Search NIS + Naik Kelas), dan Guru (CRUD + Import + Jabatan/Wali Kelas/Struktur Organisasi).Milestone 3 (Modul E-Learning): Bangun Jadwal Pelajaran KBM, CRUD Materi & Tugas, Jadwal Materi/Tugas, antarmuka Ruang Belajar Siswa, pencatatan presensi otomatis, penilaian tugas oleh guru, serta cetak/export Kehadiran Harian, Bulanan, dan Rekap Nilai E-Learning.Milestone 4 (Modul Persiapan CBT & Bank Soal): Bangun Jenis Ujian, Ruang, Sesi, Atur Ruang/Sesi Siswa, Nomor Peserta, Bank Soal 5 Tipe AKM (Editor + LaTeX + Arabic Font + Line Connector Menjodohkan + Import Word/Excel), Jadwal Ujian, Alokasi Waktu, Pemetaan Pengawas, dan Token Ujian.Milestone 5 (Engine Ujian Siswa, Monitoring, & Rekap): Bangun Halaman Login & Lembar Ujian Siswa (Zoom, Anti-Cheat Tab, Auto-Save AJAX), Cetak Administrasi (Kartu, Absensi, Berita Acara), Live Status Siswa (Reset Login/Waktu/Paksa Selesai/Ulang), Koreksi Ujian, Analisis Butir Soal, dan Export Rekap Nilai Excel Dinamis.Milestone 6 (Modul E-Rapor, Buku Induk, & Utilitas): Bangun Setting Rapor, Input/Import Nilai Rapor & KIKD, Input Sikap/Ekskul/Kesehatan/Prestasi/Catatan Wali, Cetak Rapor PTS/PAS & DKN, Buku Induk/Alumni, serta fitur Backup/Restore Database dan Web Installer.
